# PullUp Branded Live Prototype

This version uses the selected PullUp brand board assets:
- Magnet-wave U logo
- Color palette: #C6FF00, #7B61FF, #00D4FF, #0B0B10, #1A1A23
- Dark premium app direction

## Run

```bash
npm install
npm run dev
```

Then open the Vite localhost URL.

## Important

If you already have a dev server open, stop it with Ctrl+C, replace the folder/files, then run `npm run dev` again.
